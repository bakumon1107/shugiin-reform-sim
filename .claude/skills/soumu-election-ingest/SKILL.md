# 総務省 選挙結果調PDF の取り込み

## いつ使うか

`https://www.soumu.go.jp/main_content/*.pdf` で公開される「衆議院議員総選挙・最高裁判所裁判官国民審査結果調」を、
新しい選挙回として `data/csv/<election_id>/` と `data/json/<election_id>.json` に落とすとき。

抽出ロジック本体は選挙回に依存しない。**やることは基本的に `src/extract/elections.py` に1エントリ足すだけ**で、
それ以外に手を入れる必要が出たら「回ごとのレイアウト差」に当たっている（後述の「既知のレイアウト差」を見る）。

## 手順

### 1. PDFを取得して sha256 を記録する

```bash
curl -sSL -o raw/<番号>.pdf https://www.soumu.go.jp/main_content/<番号>.pdf
sha256sum raw/<番号>.pdf
```

`raw/SOURCE.md` に URL・取得日・sha256・ページ数・罫線の持ち方を追記する。
`run_all.py` は起動時に sha256 を照合するので、ここを間違えると必ず止まる。

### 2. 構造をプローブする

```bash
PYTHONPATH=src python3 -m extract.probe raw/<番号>.pdf
```

「表タイトル → 物理ページ / 縦罫本数 / 横罫本数」の一覧が出る。これを見て
`elections.py` の `pages` を書く。**文書に印字されたページ番号ではなく物理ページ番号**を使う
（両者のオフセットは回によって違う）。

### 3. `elections.py` にエントリを足す

`ElectionConfig` を1つ増やして `ELECTIONS` に登録する。
`parties` は空のまま一度 2. のプローブを党派収集モードで回すと、貼れる形で出てくる。

```bash
PYTHONPATH=src python3 -m extract.probe raw/<番号>.pdf --parties <election_id>
```

出力には表題の断片（「（１）届出政党等別」など）が混ざるので、党派名だけを選んで貼る。

### 4. 抽出 → 検証 → JSON

```bash
PYTHONPATH=src python3 -m extract.run_all   <election_id>
PYTHONPATH=src python3 -m verify.run_verify <election_id>
PYTHONPATH=src python3 -m build_json        <election_id>
```

### 5. 目視スポットチェック

```bash
PYTHONPATH=src python3 -m verify.spotcheck <election_id>
```

seed 固定で12選挙区＋4ブロックを抜き出す。出力に `PDF p<n>` が付いているので、
**Readツールでその物理ページを画像として開き、1行ずつ突き合わせる**。
確認した行は `tests/test_extract.py` にゴールデンとして固定する。

### 6. リグレッション（必須）

```bash
./run_regression.sh
```

共通コード（`common.py` / `t_*.py`）は全選挙回で共有している。
**新しい回のために1行でも共通コードを触ったら、必ず全回を回し直す。**

## 完了条件（ここを満たすまで「取り込めた」と言わない）

- `run_regression.sh` が「リグレッション: 全通過」で終わる
- `reports/verification_report_<election_id>.md` の全チェックが PASS
- とくに次の2つは必達:
  - **B1** 全選挙区で `Σ候補者得票 = 供託物没収点 × 10`
  - **C1** `Σ表(13)候補者得票（党派別） = 表(4)党派別得票数` が小数まで一致
- 目視スポットチェックで抽出値とPDFが一致

## 落とし穴（すべて実際に踏んだもの）

### 数値

- **float を使わない。必ず `Decimal`。** 同姓同名の按分票で小数第3位まで出る。
  float にすると「Σ得票 = 党派別得票数」の完全一致検証が壊れる。
- **按分票は切り捨てられる。** `Σ候補者得票` は `有効投票総数` を最大1票弱下回る。
  完全一致を要求してよいのは按分票を含まない選挙区だけ。比例代表でも同じことが起きる。

### レイアウト

- **列境界は `page.edges` から取る。** 罫線を `page.lines` で持つPDF（第51回）と
  `page.rects` で持つPDF（第50回）がある。`edges` だけが両方を拾える。
- **語ではなく文字（`page.chars`）でセルに割り付ける。**
  `extract_words` は列をまたいで語を結合してしまう（順位「1」＋党派名「自由民主党」→「1自由民主党」）。
- **2段組みページは段ごとに `page.crop` してから読む。** そうしないと左段末尾と右段先頭が結合する。
- **表領域は横罫で区切る。** ページ末尾の脚注（※…）やノンブルを見出し・データとして拾ってしまう。
- **罫線のないサブ列がある。** 表1(2)/3(2)の「新前元計」は罫線がなく `35412` のように連結して見える。
  党派列を4等分して文字を割り付けると分離できる。

### 表記ゆれ（回によって違う）

| 概念 | 第51回 | 第50回 |
|---|---|---|
| 政党の列見出し | 党派 / 党派名 | 届出政党等 / 政党等名 |
| 行見出し | 都道府県 / 選挙区 | 区分 / 比例代表区 |
| 表(8) の先頭列 | なし | 通し番号列がある |
| 年齢段階の数字 | 半角 | 全角 |

**ラベル決め打ちで行・列を探さない。** 都道府県名や既知の党派名が入っている列を実測で探す
（`locate_pref_column` / `_block_pref_header` がその実装）。

### 氏名の突合

表(13)と表(11)は同一人物を別表記で印字することがある。突合には `name_key()` を使い、
それでも残ったものは「ブロック×党派で残り1対1」で対応づける。実例:

- 異体字セレクタの有無: `大塚拓` ⇄ `大塚󠄆拓`(U+E0106)
- 小書き仮名: `三ッ林ひろみ` ⇄ `三ツ林ひろみ`
- 届出名と戸籍名: `しもの幸助` ⇄ `下野幸助`
- 高座名: 表13「やなぎや東三楼」/戸籍名「稲葉昭義」 ⇄ 表11「柳家東三楼」
- 旧字体: `赤沢りょうせい` ⇄ `赤澤りょうせい`
- かなの誤植: `たなはし泰文` ⇄ `たはなし泰文`

サロゲートペアの漢字（`𠮷田綾` U+20BB7）もそのまま保持すること。

### 制度

- **比例代表の議席配分は素のドント式では再現できない。**
  小選挙区で当選済みの者と、惜敗率欄が「×」の者（供託物没収点未達で名簿記載なしとみなされる）は
  当選人になれない。名簿が尽きた党派への配分は打ち切られ、残りは他党に回る（公選法95条の2第4項）。
  `dhondt(votes, seats, capacity)` の `capacity` がこれ。第51回の南関東・自民は
  名簿35人中「当選可能」4人で、獲得議席も4だった。
- **表(4)/(6) は諸派を合算する。** 表(13)では `（再生の道）` のように団体名が個別に出るが、
  集計表では `諸派` にまとめられている。`aggregate_party()` で畳んでから突合する。

### 設計上の約束

- **未知の党派名が出たら黙って落とさず例外で止める。** 抽出漏れを静かに通すより止まるほうがよい。
- CSVが正、JSONは派生物。`build_json.py` は生成後にJSONを再集計してCSVと突き合わせる。
